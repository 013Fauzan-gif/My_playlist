# Piringan

Playlist mini untuk lagu yang kamu suka. Tambahkan file mp3, tekan judulnya, lalu piringan hitam ikut berputar selama musik diputar.

## Fitur

- Tambah lagu dari file di komputer, atau seret file ke halaman
- Putar lagu dengan menekan judulnya
- Piringan hitam berputar saat musik jalan, dan berhenti di posisinya saat dijeda
- Lengan pemutar turun ke piringan saat lagu diputar
- Tombol sebelumnya, jeda, dan berikutnya
- Daftar lagu tersimpan di browser lewat IndexedDB

File musik tidak ikut disimpan di folder project. Lagunya hanya ada di browser yang kamu pakai.

## Cara menjalankan

Buka `index.html` di browser. Tidak perlu instalasi, server, atau internet.
